## 🚀 How to Test Locally in Chrome / Edge / Brave

1. Open your browser and navigate to:
   - **Chrome:** `chrome://extensions/`
   - **Edge:** `edge://extensions/`
   - **Brave:** `brave://extensions/`
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** (or "Load unpacked extension").
4. Select the `F:\webcamtestlive.com\extension` folder.
5. The extension will instantly appear in your toolbar! Click it to test the launcher popup.

## 🌐 Store Submission Step-by-Step

### 1. Google Chrome Web Store (DR 96 Authority Backlink)
1. Go to the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
2. Sign in with your Google Account (one-time $5 developer registration fee if new).
3. Compress the contents of the `extension` folder into a `.zip` archive (containing `manifest.json`, `popup.html`, `popup.css`, `popup.js`, and the `icons` directory).
4. Click **Add new item** and upload the `.zip` file.
5. In the Store Listing tab:
   - **Name:** Webcam & Mic Test Live - Audio & Video Diagnostics
   - **Summary:** Fast private webcam test, microphone check, video recorder, and screen diagnostic.
   - **Homepage URL:** `https://webcamtestlive.com` *(This is your permanent DR 96 Google backlink)*
   - **Category:** Productivity / Tools
6. Click **Submit for review**. Review typically takes 24–48 hours.

### 2. Microsoft Edge Add-ons (DR 95 Authority Backlink - FREE)
1. Go to [Microsoft Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview).
2. Developer registration for Microsoft Edge is **100% FREE**.
3. Click **Create new extension** and upload the exact same `.zip` file.
4. Set Homepage URL to `https://webcamtestlive.com`.
5. Submit for certification (typically approved within 24 hours).

### 3. Firefox Add-ons AMO (DR 92 Authority Backlink - FREE)
1. Go to [Mozilla Add-ons Developer Hub](https://addons.mozilla.org/developers/).
2. Click **Submit a New Add-on** and upload the archive.
3. Set your Support / Homepage URL to `https://webcamtestlive.com`.
